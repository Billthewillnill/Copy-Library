Copy Blocks, { } Wraps & Embedded Buttons

Wrap copied text inside { and }. Use \{ or \} for literal braces. Add one or more Button: Title / Link / Hover lines to show buttons right inside the copy card.

[Copy]
Title: Greeting & Portal
Description: Optional note
Button: Open Portal / https://example.com / Optional hover tip
Button: Docs / https://docs.google.com
Text: {
Hello! Literal braces look like \{this\}.
}
Current Clipboard Wrap (###)

Place ### anywhere inside { ... } to insert whatever is currently on your clipboard when you click Copy.

[Copy]
Title: Wrap Clipboard in Quotes
Text: {"###"}
Interactive Inputs & Option Pickers
  • [Text] — Prompts you to type text before copying.
  • [Number] — Prompts for numbers & decimals only.
  • [Time] — Opens an interactive clock to pick a time.
  • [Opt 1: Copied 1 / Opt 2: Copied 2] — Choose between options separated by /. Use : to separate label from copied text (omit : to copy the label itself).
[Copy]
Title: Quick Message
Text: {Hi [Text], your order #[Number] is ready at [Time]. [Pickup: We will see you inside! / Curbside: Text when outside.]}
