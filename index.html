Copy Blocks & Embedded Buttons

Wrap copied text inside { and }. Use \{ or \} to include literal braces. Add one or more Button: Title / Link / Hover Text lines (hover text optional). 

[Copy]
Title: Support Reply
Description: Standard reply
Button: Portal / https://example.com / Open portal
Text: {Hello! Here is \{your info\}.}
Clipboard Wrap (###) & Links

Put ### anywhere inside {...} to insert your current clipboard. For example, {"###"} wraps quotes around your clipboard. 

[Copy]
Title: Wrap in Quotes
Text: {"###"}

[Button]
Title: Google Drive
Link: https://drive.google.com
Hover: Open Drive
Interactive Inputs & Option Pickers
  • [Text] — Prompts you to type text before copying.
  • [Number] — Prompts for numbers & decimals only.
  • [Time] — Opens an interactive clock to pick a time.
  • Add (Title) or (Title / Description) inside [Text (...)], [Number (...)], or [Time (...)] to customize the popup header and description.
  • [Opt 1: Copied 1 / Opt 2: Copied 2] — Choose between options separated by /. Use : to separate label from copied text (omit : to copy the label itself).
[Copy]
Title: Quick Message
Text: {Hi [Text (Customer Name / Enter their first name)], your order #[Number (Order #)] is ready at [Time (Pickup Time)]. [Pickup: We will see you inside! / Curbside: Text when outside.]}
